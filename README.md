# Good UX Skills

A Cursor agent skill for designing and reviewing interfaces. `SKILL.md` is self-contained: decision load, memory, visual grouping, familiarity, speed, progress, complexity, and how people remember an experience.

## Install

Copy this folder, or symlink it, into your personal skills directory:

```bash
ln -s "$(pwd)" ~/.cursor/skills/good-ux-skills
```

Cursor reads `SKILL.md` from there. Ask for a UX design, a usability review, or good UX.
